## Description of the project and the problem (max 150 words)
A part that looks right in CAD often fails on the printer or in assembly. One AI call can draw a box, but making it fit a real board, print cleanly and assemble needs several kinds of expertise. ScienceClaw gives each kind to a specialist agent that owns one real tool and its own part of the design, with no boss: fixes outside an agent's part become requests to the owner, and plain code keeps an edit only if no check gets worse. We built two part families. Enclosures: four agents (Design, Assembly, Manufacturing, Fit) took a naive Raspberry Pi 5 case from 20 local check failures to 0 and produced a Formlabs .form file with 0 PreForm warnings. Brackets: specialists design load-bearing supports and test them with CalculiX finite-element simulation before printing. Every decision is traceable in the log.

## Formlabs prize (max 250 words)
We put Formlabs PreForm inside the design loop instead of at the end. Our Manufacturing agent calls the PreForm Local API (PreFormServer 3.64.2) and acts on real warnings. On our Raspberry Pi 5 case, PreForm's auto-orient found one resin-trapping cup in the base. The agent's orientation tool then compared six orientations in real PreForm (cups, supports, time) and chose flat for both parts: 0 warnings, base and lid on one Form Studio 1 platform, Alpha Fast V1 at 0.15 mm, 23.0 minutes and 61.9 ml of resin. The output is a .form file that prints as is, plus the same design as SLA STL, an FDM version and STEP for Onshape. The Fit agent is built for printer-specific tolerances: it reads clearances measured on a printed tolerance plate for one printer and resin, and labels every value that still comes from the design guide. Printer, material and layer height are one setting recorded in every output, so results never mix setups. What we have not shown yet: the tolerance plate is not printed, several part sizes are typical values marked UNVERIFIED, and the design run itself still ended with the cup warning because the orientation tool ran after the loop. Next we move it into the loop. Formlabs users get a design assistant that knows the printer before the first print, which saves failed prints, resin and time.
